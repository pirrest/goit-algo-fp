# Фінальний проєкт: алгоритми та структури даних

Запуск:

```bash
pip install -r requirements.txt
python main.py        # усі завдання по черзі
python task1.py       # або окреме завдання (task1.py ... task7.py)
```

Графічні вікна (завдання 2, 4, 5, 7) відкриваються через `matplotlib`; закрийте вікно, щоб продовжити.

## Завдання 6: жадібний алгоритм проти DP

Жадібний алгоритм беруть страви за найкращим співвідношенням калорій до вартості, тому не завжди оптимальний. Наприклад, для бюджету 100 він дає 870 ккал, а DP — 970 ккал (`pizza`, `pepsi`, `cola`, `potato`).

## Завдання 7: висновки

Симуляція 1 000 000 кидків двох кубиків (`seed=42`), графік — `task7_plot.png`:

| Сума | Монте-Карло | Аналітично | Різниця, в.п. |
|------|-------------|------------|---------------|
| 2    | 2.81%       | 2.78%      | +0.029        |
| 3    | 5.53%       | 5.56%      | −0.022        |
| 4    | 8.32%       | 8.33%      | −0.017        |
| 5    | 11.10%      | 11.11%     | −0.011        |
| 6    | 13.88%      | 13.89%     | −0.005        |
| 7    | 16.63%      | 16.67%     | −0.037        |
| 8    | 13.93%      | 13.89%     | +0.043        |
| 9    | 11.15%      | 11.11%     | +0.036        |
| 10   | 8.29%       | 8.33%      | −0.042        |
| 11   | 5.59%       | 5.56%      | +0.030        |
| 12   | 2.77%       | 2.78%      | −0.005        |

- Найбільше відхилення від аналітичних значень — близько 0.04 в.п., тобто результати Монте-Карло збігаються з теорією з точністю до сотих часток відсотка.
- Форма розподілу відтворена коректно: симетрія відносно суми 7, найімовірніша сума — 7 (≈16.7%), найменш імовірні — 2 і 12 (≈2.8%).
- Похибка методу спадає приблизно як 1/√N: зі збільшенням кількості кидків результат ще ближче до аналітичного, а за малих N відхилення помітно більші.
- Висновок: аналітичні розрахунки (кількість комбінацій / 36) підтверджені симуляцією.
